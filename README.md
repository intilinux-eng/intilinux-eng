## Projects

- **[vscode-recent-workspaces-linux](https://github.com/intilinux-eng/vscode-recent-workspaces-linux)**: recent VS Code workspaces in the Linux taskbar (KDE Plasma), like the Windows Jump List. Python, GLib, systemd.
- **[scrample-pingpong-bench](https://github.com/intilinux-eng/scrample-pingpong-bench)**: zero-copy IPC latency benchmark for Eclipse S-CORE `score::mw::com`, with notes on the middleware and Linux real-time tuning. C++, Bazel.
- **[netlog](https://github.com/intilinux-eng/netlog)**: your network traffic explained in plain sentences: which program talks to whom, what is new, what is exposed. Python, Scapy.
- **[iaw-scan-3](https://github.com/intilinux-eng/iaw-scan-3)**: diagnostics and data logging for 1990s Fiat, Lancia and Alfa Romeo engines (Marelli IAW ECUs) over a K-line cable. C#, fork of IAW Scan 2.
- **[icloud-sync](https://github.com/intilinux-eng/icloud-sync)**: two-way automatic iCloud Drive sync on Linux, built on rclone bisync. Python.
